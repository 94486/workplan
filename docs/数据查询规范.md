# 龙猫工作统计台 — 数据查询规范

本文档描述**其他设备 / 程序如何通过数据接口只读查询**工作台的数据（工作任务、预设、收入配置等）。

- **适用对象**：手机、另一台电脑、自研程序等，只要持有对接码即可读取。
- **鉴权**：与「远程数据导入（推送）」共用同一个**对接码**，请求头 `X-Api-Key` 携带。
- **只读**：本接口不修改任何数据；需要写入时请走推送（见 [docs/数据对接API.md](数据对接API.md)）。
- **数据一致性**：返回字段与「导出 JSON」「推送数据」完全一致，查询结果可直接作为推送 `data` 回传。

---

## 1. 接口地址

```
GET /api/push/query
```

本地程序：`http://127.0.0.1:8000/api/push/query`
局域网 / Docker：把地址换成服务器 IP，如 `http://192.168.1.100:8000/api/push/query`（Docker 部署已监听 `0.0.0.0`，见第 7 节）。

## 2. 鉴权方式

请求头携带对接码（与推送共用，重生成后旧码立即失效）：

```
X-Api-Key: wd_xxxxxxxxxxxxxxxxxxxx
```

| 情况 | 结果 |
|---|---|
| 未携带 / 携带错误对接码 | `401 {"detail": "对接码无效或缺失"}` |
| 携带正确对接码 | `200` 返回数据 |

> 对接码在「数据对接」弹窗中查看 / 重新生成。**对接码即数据读取凭证，请勿泄露**；泄露后在界面重新生成即可让旧码全部失效。

## 3. 查询参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `scope` | string | `all` | 查询范围：`all`（全部）/ `works`（日薪工作）/ `presets`（日薪预设）/ `monthly_works`（月薪任务）/ `monthly_presets`（月薪预设）/ `monthly_settings`（月薪收入配置） |
| `from` | string | 空 | 计划日期起始 `YYYY-MM-DD`（只作用于日薪/月薪工作） |
| `to` | string | 空 | 计划日期截止 `YYYY-MM-DD`（只作用于日薪/月薪工作） |
| `status` | string | 空 | 状态过滤：`pending`（待完成）/ `done`（已完成）（只作用于日薪/月薪工作） |

**过滤规则**：
- `from` / `to` / `status` 只对带日期的 `works`、`monthly_works` 生效；预设与收入配置不受过滤影响。
- 日期必须合法（如 `2026-09-01`），非法日期返回 `422`；`from` 晚于 `to` 返回 `422`。
- 参数可组合：`scope=works&from=2026-08-01&to=2026-08-31&status=done`。

## 4. 响应结构

```json
{
  "app": "WorkDashboard",
  "version": 2,
  "exported_at": "2026-09-15 12:00:00",
  "scope": "works",
  "filter": { "from": "2026-08-01", "to": "2026-08-31", "status": "done" },
  "count": 2,
  "data": {
    "works": [
      {
        "id": 1,
        "name": "需求评审",
        "work_type": "regular",
        "duration_hours": 1.5,
        "planned_date": "2026-08-03",
        "expected_income": 300,
        "notes": "",
        "status": "done",
        "actual_duration_hours": 1.5,
        "completed_date": "2026-08-03",
        "actual_income": 300,
        "created_at": "2026-08-03 09:00:00",
        "updated_at": "2026-08-03 18:00:00"
      }
    ]
  }
}
```

| 字段 | 说明 |
|---|---|
| `app` / `version` | 固定标识（`WorkDashboard` / 2），便于识别来源 |
| `exported_at` | 查询生成时间 |
| `scope` / `filter` | 回显本次查询的参数 |
| `count` | `data` 内全部记录数合计 |
| `data` | 按 `scope` 返回对应键：`works` / `presets` / `monthly_works` / `monthly_presets` / `monthly_settings` |

**各类数据字段**（与导入/推送格式完全一致）：

| 数据键 | 字段 |
|---|---|
| `works`（日薪工作） | name, work_type, duration_hours, planned_date, expected_income, notes, status, actual_duration_hours, completed_date, actual_income（另有 id / created_at / updated_at） |
| `presets`（日薪预设） | name, work_type, duration_hours, expected_income, notes |
| `monthly_works`（月薪任务） | name, work_type, duration_hours, planned_date, status, actual_duration_hours, completed_date, notes（**无收入字段**） |
| `monthly_presets`（月薪预设） | name, work_type, duration_hours, notes |
| `monthly_settings`（月薪收入配置） | month_key, regular_income, other_income, updated_at |

> `work_type`：`regular`=常规工作、`other`=其他工作；`status`：`pending`=待完成、`done`=已完成。

## 5. 调用示例

### curl

```bash
# 查询全部数据
curl -H "X-Api-Key: wd_xxxxxxxx" "http://127.0.0.1:8000/api/push/query?scope=all"

# 只查 2026-08 月已完成的日薪工作
curl -H "X-Api-Key: wd_xxxxxxxx" \
  "http://127.0.0.1:8000/api/push/query?scope=works&from=2026-08-01&to=2026-08-31&status=done"

# 只查月薪收入配置
curl -H "X-Api-Key: wd_xxxxxxxx" "http://127.0.0.1:8000/api/push/query?scope=monthly_settings"
```

### Python（urllib，无第三方依赖）

```python
import json, urllib.request

url = "http://127.0.0.1:8000/api/push/query?scope=all"
req = urllib.request.Request(url, headers={"X-Api-Key": "wd_xxxxxxxx"})
with urllib.request.urlopen(req, timeout=10) as resp:
    data = json.loads(resp.read().decode("utf-8"))
print(data["count"], data["data"]["works"])
```

### PowerShell

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/push/query?scope=all" -Headers @{ "X-Api-Key" = "wd_xxxxxxxx" }
```

## 6. 常见错误

| 状态码 | 场景 |
|---|---|
| `401` | 未携带 / 携带错误对接码 |
| `422` | `scope` 非法；`from`/`to` 非 `YYYY-MM-DD`；`from` 晚于 `to`；`status` 非 `pending`/`done` |

## 7. Docker 部署下的查询

Docker 镜像已内置 `HOST=0.0.0.0`，容器内外均可访问同一套接口：

```bash
# 容器内
docker exec work-dashboard curl -H "X-Api-Key: wd_xxxxxxxx" "http://127.0.0.1:8000/api/push/query?scope=all"

# 宿主机 / 局域网（端口已映射 8000）
curl -H "X-Api-Key: wd_xxxxxxxx" "http://服务器IP:8000/api/push/query?scope=all"
```

> Docker 部署时对接码与本地运行互不影响（数据库独立在数据卷 `/data/works.db`）。查询接口与推送接口使用同一鉴权与同一数据库，无需额外配置。

## 8. 查询 → 推送的闭环

查询结果可直接作为推送 `data` 回传，实现「读取 → 处理后写回」：

```json
{
  "source": "我的查询程序",
  "pushed_at": "2026-09-15 12:00:00",
  "data": {
    "works": [ /* 从查询结果 data.works 取出的记录 */ ]
  }
}
```

- 推送时多余字段（如 `id` / `created_at`）会自动忽略；
- 推送进入待审查箱，在界面确认后以合并模式入库（重复自动跳过）。
