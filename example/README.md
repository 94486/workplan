# Example 示例数据

本目录存放用于测试「龙猫工作统计台」的模拟数据备份文件。

## 文件说明

| 文件 | 内容 |
|---|---|
| `demo_backup_2months.json` | 两个月（2026-07、2026-08）模拟数据，系统标准备份格式，可直接导入 |

## 数据口径

- **日薪工作**：共 50 条
  - 常规工作：每个工作日 1 条（时长 7h），7 月合计约 ¥8,050、8 月合计约 ¥7,980；
  - 其他工作：每月 3 条，合计约 ¥1,000；
  - 状态：多数已完成，8 月最后几天为待完成。
- **月薪任务**：共 40 条（7 月、8 月各 20 条，无收入字段），约 2/3 已完成。
- **月薪收入配置**：`month_key = 2026-08`，常规工作收入 ¥8,000、其他工作收入 ¥1,000。
- **预设**：日薪预设 3 条、月薪预设 2 条。

## 使用方法

1. 启动程序后，进入 **数据导入**（顶部工具栏按钮）；
2. 选择 `demo_backup_2months.json`；
3. 导入方式建议选 **覆盖导入**（会先清空当前数据再写入示例数据），
   如只想在现有数据上叠加示例可选手动清理后导入；
4. 导入完成后，切换「日薪模式 / 月薪模式」即可查看看板、统计报表。

> 提示：请勿在真实数据目录（`data/works.db`）上直接覆盖导入，
> 测试前请先导出一份真实数据备份。示例数据仅用于功能演示与界面测试。

## 验证参考

导入后预期的关键统计（月薪模式，截止上月 2026-08）：

- 月薪总收入：¥9,000（常规 8,000 + 其他 1,000）
- 上月完成工时：92h（常规 80h + 其他 12h）
- 小时工资：常规 ¥100/h、其他 ¥83.33/h、综合 ¥97.83/h
